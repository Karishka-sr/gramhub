GramHub

Лаунчер для клиентов Telegram. Этот адрес отдаёт каталог, который читает приложение.

Каталог клиентов clients.json — список клиентов с release-APK Скачать GramHub последний релиз на GitHub Исходный код github.com/Karishka-sr/gramhub Телеграм-канал t.me/NeonBeatt — новости и обновления

В приложении этот адрес задан по умолчанию: Настройки → Каталог клиентов → https://karishka-sr.github.io/gramhub/clients.json
